Finding your CPU Architecture

You must know how to do this as it is what is going to help us find out what version of an operating system you need to install. As a basic overview different CPU architectures have different registers in the CPU that make them each read code differently. Some architectures are missing many registers all together at the CPU level like RISC-V and handle software much different than a heavy CPU architecture like AMD64.

The main CPU architectures you are likely to have will be i386, i486, i586, i686, and AMD64 depending on the age of your machine. For the minority of you you could also have ARMv7 or lower, or even PowerPC, If your running SPARC or m68k and older stuff like that you would most likely already know it so I won't cover it much in this section.

Now to clear up some confusion before we begin as this is a common one. The i infront of all those architectures stands for Intel but this does not mean you are running an Intel CPU and the same goes for AMD64 you can have an Intel chip that's AMD64. This is because Intel created the 32 bit architecture and licensed it to AMD and then vise versa for 64 bit AMD created it and licensed it to Intel.

The next clarification I will add is the 32 bit vs 64 bit architectures. i386, i486, i586, i686 are all really similar and will usually be packaged together and labeled as i386. If you have any of these you would want the i386 versions. For PowerPC users 99% of you will be using old Powermacs/Powerbooks as this is an IBM server architecture no longer sold in consumer hardware. The other 1% of you using some obscure PowerPC desktop/laptop I will try to cover stuff for you but for the most part you will be very limited vs the PowerPC mac support. PowerPC macs usually have software labelled macppc this does not mean mac users in general this is specific to PowerPC macs and will not work on your Intel Macbook! These are all 32 bit architectures along with ARMv7. ARMv7 is much more obscure and it's unlikely you are running it so I won't cover it much. This are things like the 1st gen Raspberry Pi Zero.

If your running a Powermac G5 you are no longer running 32 bit and are now running IBMs 64 bit version of PowerPC. For you users which will most likely be a decent chunk of the PowerPC users you need to watch for a few things. First you can run macppc if you want, however you will be running everything in 32 bit. 32 bit software support is dying at a faster rate these days but not every OS is going to offer G5 support on their ppc64 software. I will cover this moving forward but do keep it in mind you may not get the perfect blend of what you want with 64 bit software and may have to use 32 bit. You will also be limited to 4GB of Ram on a 32 bit OS, the early single CPU models supported a max of 4GB while the dual CPUs could do 8. However the later generation models that support DDR2 RAM could all handle up to 16GB of RAM. So keep this in mind, and yes you most likely want as much RAM as you can get especially for an old computer.

Now the major architecture over half of you are probably using is AMD64. This is a 64 bit architecture and has been in production for consumer hardware for nearly 2 decades! You guys will have the least performance hits and these modifications we will talk about in the parts moving forward you will see a very noticable difference. Your systems will also all have SATA support and since they are 64 bit will be supported by software for a long time moving forward. This will open your options for running things much more than the others.

Alright but how do you find your architecture? The most simple way is to try to find a model name and number for your computer. As an example Dell Optiplex 7010 or Macbook Pro 13 inch (2009). Now these are very vauge and aren't going to tell you your exact computer specs and that's fine. Companies aren't selling 2 different CPU architectures with the same computer model. From here we can look up the model and find the various CPUs sold in that model for our examples the Macbook uses a Core 2 Duo which is 64 bit (I will have a list below explaining which each are) and for the Dell Optiplex 7010 it shows on the specs pdf 3rd gen i5/i7 and 2nd gen i3 CPUs these are also all 64 bit chips. If this is confusing I will show you another way to find your exact cpu model with a command for your current OS.

On Windows press the Windows Key + R this will load up a window called 'run'. In here we just want to type msinfo32.exe. Once you enter that your looking for something called Processor you can compare that model to the chart below. You can also find a window in the control panel for system information that will tell you.

On MacOS 10 and newer because it runs on a BSD base you can open a terminal and enter the following sysctl -n machdep.cpu.brand_string and press enter and it should print back a line with the CPU info. You can also find the CPU by clicking the Apple logo in the top left corner and clicking on About this Mac. If your running macOS 9 you are running a PowerPC CPU. For macOS 8 and 7 (System 7) users it could be either m68k or PowerPC. I am not going to cover m68k in this guide. For PowerPC macs you will be running macOS 8.1 or higher (if yours is running macOS 8.0 your PowerPC mac is much more complex to get working for this guide due to bootloader issues, sorry. It can be done but I won't be guiding you through it.). Anyways for macOS 8 to find your CPU click the Apple logo in the top left and then click on Apple System Profiler and look for processor.

Linux users, because of the various desktop environments yours will just be limited to a terminal. Run the command cat /proc/cpuinfo and that will output your CPU model.

While you are here you should also write down the actual model number of the CPU so instead of just i7 it would be like i7-3700 or whatever. If your on Mac it doesnt show you in the "About this Mac" screen it will just say like 2.6GHz Core i7. You will need to click on the option in that menu called "System Report". You will then see the Model Identifier which you will need like Macbook Air 9,1 and you also will want that CPU ID from earlier. Possible Upgrades

Now that you know your CPU and architecture we can move onto possible upgrades for your machine. Now depending on age this can be expensive due to it being "vintage" and it could also be cheaper to just buy a whole new machine. You also do not need to do any upgrades for this guide. I am only providing some insight for those interested.

Firstly, you can get some really good machines on a budget. If your interested in doing upgrades and it's over 200 dollars I would say you should start considering a new ("used") machine. At the time of writing you can find some really good deals on refurbished and used hardware. For laptop users you have various Lenovo Thinkpads like the T420s, T430s, T440s, and T450s you can also replace the s for a p in those model names for a thicker and usually faster laptop. These are on ebay for under 200 dollars nearly all the time and are all solid AMD64 machines. You can also find older Macbooks for under 200 but it usually won't be as fast as the Lenovo's. For desktop users if you don't need any PCI-E expansion slots (for graphics cards for games and other stuff) then you can find Dell Optiplex 3050 refurbished on Amazon or ebay also for under 200 dollars and they even support M.2 SSDs. If you need a GPU (Graphics Card) then your looking at 3rd or 4th gen intel desktops like Dell Optiplex, Lenovo Thinkcentres (lots of these from schools upgrading), and HP Z400 and Z420 if you can find them. I have even seen OWC (macsales) selling Mid 2011 Mac Minis for 40$ for the base config which will be way faster than say a Powermac if your really till on that old of hardware.

Now for upgrades themselves, what can you actually do? The biggest one in terms of file transfers and load times is going to be an SSD (Solid State Drive). This is used to replace your HDD (Hard Disk Drive). Unlike a Hard Drive that uses a spinning disk to read your data off of an SSD is a flash chip and can fetch the data much faster. Sadly to make things more complicated not all SSDs are built the same and the marketing for them can mislead you. You have a few types of NAND (The chip storing your data). You have SLC (Single Layer Cell), MLC (Multi Layer Cell), TLC (Triple Layer Cell), QLC (Quad Layer Cell) and recently PLC (Penta Layer Cell). Now what you want depends on your use cases. A thing to look out for is Samsung SSDs where they say everything is MLC which is technically correct but they will use the term MLC 3 bit for TLC and MLC 4 bit for QLC. This is misleading you into thinking your getting a 2 bit MLC drive. SLC isn't really used as a NAND in consumer drives anymore just for a faster cache. SLC is the fastest and most durable. As you go down the list through MLC to TLC and QLC the drives lifespan decreases and this is what your mainly paying for. A common metric these drives use is called TBW (Terrabytes Written) this is the recommend amount of writes to the drive you should get before it has issues. TLC is usually rated around 1200-1500 TBW and QLC is rated around 500TBW on average. MLC and SLC will be out of budget and not needed for these old machines.

The other thing you should be concerned about with your SSD is if it has a cache at all. Cheaper SSDs will drop the cache all together which won't affect you unless your doing lots of writing to the drive, like installing your OS might be slower and because of this these drives are usually rated a little slower than cahce based SSDs. Either way it will still be way faster than your HDD.

Here is a list of some SSDs to give you some ideas. I would strongly recommend considering getting at the least an SSD but again it is not needed at all. Drives like the Crucial BX500, Patriot P210 and Kingston A400 are 3 budget TLC drives without a cache and have low TBW lifespans. The Patriot P210 is the same as the P220 just with a cache. These drives work fine but should really be only considered if you need to save the cost difference. Your much better upgrading to a Crucial MX500 which will be the best bang for your buck. The best drives but most expensive will be a Samsung EVO don't worry about the PRO.

The other item you can upgrade on almost all machines even laptops is RAM. RAM will not make your PC faster but instead holds the data of applications running in the background. The more RAM you have the larger programs you can run and more programs you can run at a time. If your at the max of your RAM usage then yes having more RAM would feel like a speed increase because your PC isn't stalling trying to find space to open the next program. There are 2 different types of RAM. You have a DIMM which is your standard long stick usually found in servers and desktops and then you have SO-DIMM which is a small stick found in small PCs and laptops. The other thing you need to find is the generation of RAM. For this guide all of the CPU architectures we have talked about use a type of RAM known as DDR (Double Data Rate) and each generation is marked with a number. For example a Powermac G3 and G4 uses DDR and later models of the G5 use DDR2. Most of you are going to be using DDR3 then probably DDR4 or DDR2. We will install a new OS later in this part or the next one which will use less RAM as well so you may not need this upgrade as much.

First we need to find out if you can even upgrade your RAM and the max capacity. Pretty much all desktops you can upgrade your RAM on unless it's already maxed out for your motherboard/chipset. For laptops you should be able to except maybe like netbooks and super thin and light laptops. Around 2016 companies started removing RAM upgrading for faster and lower power draw on board soldered RAM. Apple did this around 2013. If your on a laptop you will 100% need SO-DIMM RAM, Desktop 95% of the time you need DIMM unless you have a small desktop then it can be SO-DIMM. If your on a Mac it's really simple to check if you can upgrade the RAM which is nice Apple includes all this info. If you go to the top left corner and click the Apple icon and then click on "About This Mac" in that window you will see another button called "System Report". Cick on that and then in the left side menu under "Hardware" find "Memory". Once you click on that the first item says Memory slots it should be selected but if not click on it now near the middle it will show the info for that item. First it will say ECC then below that it will say Upgradable Memory and a Yes or No beside it. If it's a yes we can upgrade the RAM. For Macs I would recommend sticking with the exact speed listed as they can be very picky about faster RAM. Using your model number from the architecture section you can visit the site macsales (linked below this paragraph) and find your exact model and the ram it uses. For example a 2011 Macbook Pro 2011 uses DDR3 1333MHz SO-DIMM. Now you can buy RAM from OWC if you want I have used it before and it works great. But you can also try to find the same RAM on Amazon or ebay for cheaper.

OWC (Macsales) - https://eshop.macsales.com/shop/apple/memory/

Now for the rest of you it's not as simple. Your gonna need to get that model number from the architecture section and look it up with the words "specs" or "spec page". It will probably be a pdf if you can't find it there is another way to find out but it's more guess work. On the spec page it should tell you the Memory options for the system and you can see the max from there (which is sometimes lower than the actual max). If you can't find your spec page there is 2 ways we can get a pretty good estimate of what you can use. First we will need the exact CPU model from earlier from there we look it up, for Intel you will look up the model name and add "ark" to the end this should find the Intel Ark database with that chip specs, for example an i7 2600K says I need DDR3 RAM and I can use up to 32GB, it will also give you a recommended speed however this is more dependent on your motherboard's capabilities. It's best to stick with their recommended speeds but if you get over say DDR3 1600MHz for this 2600K it will likely work fine. This is the same process for laptop CPUs as well. Next we need to open the computer and see how many RAM slots we have. On older laptops you used to have a specific cover over the ram slots so you just remove a few screws to check, desktop people open your case and it will be beside the large cooler some long sticks, they are 99% of the time the vertical slots, not to be confused with the horizontal ones below the cooler. Most of your desktops should have 4 slots the others will have 2 slots and the small minority of you will have 8 slots. On laptops and small desktops you will likely have 2 slots and the ram lays flat you pull the 2 metal tabs to each side of the ram and it will pop up on an angle to be removed.

Now we still need to know how much RAM you currently have to compare againt your maximum amount.
